다운로드가 안 될 때 오른쪽 위(또는 아래) ⋮ → 다른 브라우저로 열기(Chrome)를 누른 뒤 다시 버튼을 누르십시오.

설치 방법

  1. 다운로드가 끝나면 알림(또는 내 파일 → 다운로드)에서 APK를 누릅니다.
  2. '알 수 없는 앱' 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 갑니다.
  3. 설치를 누릅니다. Play 프로텍트 경고가 나오면 자세히 보기 → 무시하고 설치.
  4. 설치가 막히면 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 끕니다.
  5. 홈 화면 사무동 마스터스 실행 → 본인 이름을 선택합니다.

지난달 '골프 행사' 앱과는 별개 앱입니다. iPhone에는 설치할 수 없습니다.
